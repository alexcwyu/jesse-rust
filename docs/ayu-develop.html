Design decisions

Decision Rationale Tradeoff Evidence
Keep numerical kernels behind PyO3 NumPy bindings. Python host retains orchestration while Rust computes array results. Caller must respect each indicator warmup/empty-input contract. jesse_rust (L33) / sma (L108) / rsi (L19)
Use bounded local ephemeral coordination. Token auth, loopback-only binding and restart generations bound access and prevent silent stale-state continuation. State is lost on restart; this is not a durable or remote distributed service. run (L779) / State (L113)

Strengths and limits

Strengths

  • Actual rolling/recursive indicator bodies are exposed through a small Python-native boundary. sma (L108) / ema (L350) / rsi (L19)

Limitations

  • Market coverage, broker execution, optimizer and trading risk policy are host responsibilities; they cannot be credited as native engine capabilities here. AGENTS.md (L6) / jesse_rust (L33)
